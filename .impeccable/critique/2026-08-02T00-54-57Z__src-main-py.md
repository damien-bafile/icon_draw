## Assessor A — design review (29/40, P1 x2)

- **BLOCKER A1**: `comment_entry["undo"] = True` (main.py:139) raises
  `TclError: unknown option "-undo"` at startup — `ttk.Entry` has no `undo`
  option; the round-3 smoke test never built the full window, so it slipped
  through.
- **A2**: Accent button pressed-state bg `SURFACE2` + fg `BASE` = 2.46:1,
  below the 3:1 WCAG non-text threshold.
- **A3**: Disabled Undo/Redo buttons lack a `disabled` style mapping —
  indistinguishable from enabled.
- **A4**: Right-click on an empty cell pushes a no-op undo entry
  (`_on_erase_click` always pushed history).
- **A5**: Clear on an empty grid is silent — no status feedback.
- **A6**: `update_output` → `_refresh_actions` closure-order hazard: references
  `undo_btn`/`redo_btn` defined later in `main()`.
- Output block still the weakest element (P2 direction: typeset/bolder).
- Row 7 (Flexibility): Copy primary affordance beyond the button.

## Fixes applied in this round

1. **A1 (blocker)**: replaced the `ttk.Entry` comment field with a plain
   `tk.Entry` styled to match the theme (bg SURFACE0, fg TEXT, insertbackground,
   highlight ring). `undo` is dropped entirely — this Tk build (8.6.15)
   exposes no `-undo` option on any Entry, so native text-undo is unavailable.
   Full `main()` now builds headlessly with no crash.
2. **A2**: accent pressed-state bg changed `SURFACE2` → `BLUE` (7.79:1 vs BASE,
   ≥3:1) — pressed == active hover, which is a standard clam-theme idiom.
3. **A3**: added `disabled` maps to `TButton` and `Accent.TButton`
   (bg SURFACE0, fg SUBTEXT0, 5.65:1) so disabled buttons read as dimmed.
4. **A4**: `_erase_cell` now pushes history only when a cell actually erases,
   once per gesture (`_erase_history_pushed`); right-click on empty cells and
   right-drag erases each produce exactly one undo step.
5. **A5**: `FontGrid.clear()` returns `bool`; Clear button flashes
   "Cleared" / "Nothing to clear".
6. **A6**: reordered `main()` in dependency order; `_refresh_actions` now sits
   after its button references; the grid-bound buttons use `command=lambda:` to
   break the grid↔update_output cycle cleanly.
7. Output block: "C source:" label upgraded to a bold mono `Header.TLabel`;
   `Code.TEntry` retained for the code well.
